# BETA CLINIC

Aplicación web full-stack para la gestión de una clínica de fisioterapia: reserva de citas con control de agenda, área de paciente con seguimiento de ejercicios de rehabilitación y panel profesional.

## Alcance y propósito del proyecto

El proyecto se desarrolla como **demostración técnica de portfolio**. Su objetivo es mostrar el diseño y la implementación de una solución completa: arquitectura cliente-servidor, modelado de datos, autenticación delegada en un servicio externo, lógica de agenda resistente a la concurrencia y buenas prácticas de protección de datos en un dominio sensible.

Todos los datos son **ficticios** y la aplicación **no está destinada a su uso clínico real**. Un despliegue en producción requeriría, entre otros aspectos, una revisión legal del tratamiento de datos de salud conforme al RGPD y la LOPDGDD.
